# Common Denial Codes
Synthetic policy text for demonstration only. Not real payer rules.

Denial code CO-16 means the claim lacks information needed for adjudication. Resubmit a corrected claim with the missing field, usually a referring provider NPI or a diagnosis pointer. Do not file an appeal for CO-16.

Denial code CO-18 means the claim is an exact duplicate of a previously processed claim. Check the remittance for the original claim number before resubmitting anything.

Denial code CO-50 means the service was not medically necessary under the member's plan. This denial can be appealed with clinical notes and a letter of medical necessity.

Denial code CO-97 means the payment is included in the allowance for another service, also called bundling. Review modifier usage. Modifier 59 may be appended only when the procedures were performed at separate sessions or sites.

Denial code PR-1 means the amount was applied to the member's deductible. This is patient responsibility and is not an error.
